# EVT-028 — microphone DRC enabled and disabled

Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: QuantumENGINE microphone DRC disabled
Action: enable DRC, wait, then disable DRC

## Result

No USB transfer to the JBL device occurred during either transition. The
capture contains only the existing isochronous audio stream plus USBPcap's
initial descriptor enumeration. There were no HID Feature Reports, HID
interrupt notifications, or USB Audio class-control requests.

## Conclusion

QuantumENGINE implements microphone DRC on the Windows host rather than as a
dongle/headset setting. JamBaLinux SonicCore should therefore treat DRC as an audio
processing feature, potentially implemented with PipeWire, and not as part of
the device USB protocol.
